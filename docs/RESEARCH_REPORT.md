# 研究档案：LingBot-VLA 失败归因与决策端优化——完整证据链

**时间跨度**：2026-07-28 至 2026-08-09
**对象**：LingBot-VLA 2.0（6B，Qwen3-VL-4B + 流匹配动作专家/MoE）× RoboTwin 2.0 仿真
**研究目标**：不新采演示数据，通过对已有执行记录（成败 + 模型内部量）的推理，
让失败样本借鉴成功样本，提升闭环成功率；方法需跨任务通用、可迁移真机。

**总结论（一句话）**：从单抽离线执行数据中能可靠学到的是**状态级**成败知识
（"这个局面会不会失败"，留出集 AUC 0.76–0.99）；**动作级**知识（"同一局面下哪个
动作/抽签会成功"）在三种独立方法下均不可获得（RL 价值梯度、事后择优、对比排序均
为随机水平），且多抽对比实验证明该差异不体现在任何可观测量中——因此所有依赖
"同状态内做选择或引导"的优化路线判负，噪声彩票（42–45% 失败可被换签救回）只能
通过"观测到失败后重试"收割。

除特别标注外，本文所有数字均为**实测**。

## 0. 基础设施与方法学基线

- **双进程双环境**：策略端（`lingbotvla` env，常驻 6B bf16 ≈12.9GB）与仿真端
  （`robotwin` env，SAPIEN3 ≈5.4GB）经 websocket 通信；上游要求的单环境合并实测无必要。
- **埋点**（`lingbot_patch/`，introspect 侧信道）：每决策记录前缀读出
  （h_image/h_lang/h_query/h_query_tokens）、MoE 逐层真实选择计数与熵、流匹配噪声与
  10 步去噪轨迹；批量传输后延迟开销 +21%。
- **噪声钉死**：决策种子 = 场景种子×1000003 + 决策序号 + 抽签号×7919；钉死后同请求
  重放漂移 0（无 LoRA）/ ~1e-2（带 LoRA，bf16 归约噪声）。
- **corpus**：50 任务难度扫描 + 深采，共 1628 次尝试 / 386 失败 / 46 任务（8.3GB）。
- **bf16 底噪**：完全相同配置重跑，12–20% 场景结局翻转。由此确立评测方法学：
  **同场景配对 + 翻盘不对称性判定 + 欧拉自身重跑做底噪对照**，绝不看绝对成功率。
- **关键基线发现**：click_bell/click_alarmclock 上 42–45% 的失败换一次噪声抽签即成功
  （噪声彩票）；open_microwave 为场景决定型；exec_horizon 干预无效果。
- 评测脚本存在**无消息静默跳场景路径**（专家复检未过时 seed+=1 不打印），
  非场景表模式下两臂场景集可能漂移——配对分析必须取交集。

## 1. 阶段一：贝叶斯因果归因（判负）

**设计**：静态组件节点（感知/语言/路由/噪声/去噪/执行）× 动态值节点的 noisy-OR
因子图，分层任务偏置，NUTS 推理（离散责任解析边缘化）；值节点 = 失败决策与
**反事实配对**成功决策（真实输入空间最近邻：14 维关节 + 3 路降采样图像，
准入分位数 0.5）的差距百分位。

**归因结果**：路由以 0.928 置信度吸收主要责任（155/219 失败）。

**矫正与外部验证**：对 `e_score_correction_bias` 施加"匹配成功样本负载谱−自身"的
定向偏置（标定 scale=0.01：移动量 0.157≈目标 0.148、方向余弦 0.69；饱和检验 +10 →
份额 1.000 证明机制真实生效）。**A/B 判负**：路由担责组救回 6/77=8% vs 其他担责组
5/28=18%（方向相反，p=0.963）；净害——救 11 破 13，破坏了路由组 34% 的基线成功场景。
噪声担责组的免费检验同样阴性（翻盘 17% vs 基准 23%）。

**诊断**：六个"组件"是（场景、指令、噪声）三个真实输入的**确定性中介**，不是可
独立故障的原因；noisy-OR 把"分岔显形最敏感的断面"（路由熵）误读为故障源。
观测数据上组件级归因与可修复原因脱钩。

## 2. 阶段二：VINE 复现（arXiv 2607.10369）

### 2a. 采样器替换（零训练）——零效应，且为理论预言的验证

VINE 采样器（每步终点预测 `â=x−t·v` + 围绕 â 重注新鲜噪声）按时间镜像
（t↔1−t）适配进 `sample_actions`，查询时间栅格与欧拉完全一致，钉种子时首查询
与欧拉恒等。**配对 A/B（189 场景）**：欧拉 115 vs VINE 113；救 24/破 26，p=0.664；
两采样器不一致率 26% 高于欧拉自身重跑的 18%——采样器真实改变行为，但净效应为零。
这正是论文定理 1（终点预测保分布）的预言：**纯推理替换不该涨，收益须由 RL 兑现**。

### 2b. 离线价值梯度 RL（判负，证据链闭合）

**实现**：SARSA 目标双 Q critic（EMA 目标网络）；actor = 冻结 VLM + 36 层动作专家
attention 投影上的 7.67M LoRA；VINE 链 10 步 BPTT（前缀 KV 为常量，梯度不经 4B 主干）；
可微反归一化桥由 `feature_transform.unapply` 数值探针恢复（仿射验证误差 2e-7）。
**训练途中修复的两个失稳**：BC 损失 55 维中 41 维为填充噪声→掩码至 14 真实维；
真实 BC 尺度 ~1e-4 使固定 α 失锚、actor 骑 critic 出分布（Q 冲到 2.0）→
悲观 min(Q1,Q2) + TD3+BC 式自适应配平 + Q≤1 语义钳制。

**四次仿真裁决**（同 50 场景、同钉死噪声）：

| 配置 | critic 探针 Q(vine) | 仿真 T vs C | 判读 |
|---|---|---|---|
| bell α_q=0.2 | 0.221→0.237 | 23 vs 25 | 抖动内 |
| bell α_q=1.0（松锚5×）| 0.221→0.390 | 23 vs 26 | 抖动内 |
| alarm ep1（合法域）| 0.136→0.253 | 25 vs 26 | 抖动内 |
| alarm ep3（Q=1.41 超上界）| 0.136→1.411 | **16 vs 30（−28pp）** | 策略被破坏 |

**诊断**：critic 打分与真实成功率零相关、推得越狠伤害越大；actor 找到 350 维协调
微移（BC-MSE 恒 ~3e-5）灌高 critic 至语义不可能值；双 Q 同数据同批次训练共享盲区。
离线单抽数据支撑不了同状态方向导数。

## 3. 阶段三：Top-N 择优（判负，但机制特征全部命中）

**设计（按用户要求做归因条件化）**：场景标签**预注册**自多签记录——噪声可救型
失败 / 场景决定型失败 / 稳定成功；通过标准 = 救回集中于噪声可救类 + 场景决定类
≈0 + 稳定成功不被破坏。服务端 `sample_topn`：每决策 8 签（第 i 签种子=基准+i×7919，
**候选 0 恒等于基线**），冻结裁判打分择优，逐决策分数落盘。

**泄漏事件（用户发现）**：评测场景（800 段）在裁判训练缓冲内（alarm 25/25、
bell 25/75 重叠）→ 全部重训于零重叠干净缓冲（100000–300056 段）。副产发现：
去掉泄漏集后 **TD 自举裁判在 alarm 上失明（AUC 0.50）而 MC 分类信号存活**→
裁判改 MC 目标（bell 0.99 / alarm 0.62，天然形成强弱裁判对照）。
（RL 各 A/B 不受此泄漏影响——其评测场景 1200 段从未入缓冲，已核验。）

**结果**：总分 +1/0。归因条件化分解——场景决定型救回 **0/15**（预测命中）、
稳定成功破坏 ~6%（底噪内，命中）、噪声可救型救回 **3/12=25%**——恰为 8 选 1
盲选的期望值，p≈0.34。**定因测试**：真实同场景成败抽签对上，裁判排对
16/33=**48%**（随机）——跨场景 0.99 的"局势评估员"在同状态内完全失明。
根因：单抽数据每状态只有一签，**同状态对比样本在训练数据中数量为零**。

## 4. 阶段四：多抽对比验证（最终判负，B 类主导确立）

补齐缺失教材：全新场景段（seed 15）2 任务 × 50 场景 × 6 钉死抽签带全特征
（600 集）。RankNet 同场景成败配对（278 对，按场景分组留出），特征消融：

| 排序器输入 | 留出配对排序正确率 |
|---|---|
| 动作块 + 状态特征 | 43.5% |
| 原始噪声 ε + 状态特征 | 53.6%（n.s., p≈0.13）|
| 两者 | 46.4% |

（划分种子间散布 32–68%，方差主导；配对场景聚簇使有效样本小于 278。）

**结论**：即使给了正确的对比教材，同状态成败差异仍不可从（观测特征、动作块、
原始噪声）中预测——决定性信息在这些可观测量之外（接触级几何 + 执行混沌放大）。
推论：**该部分失败加多少预训练演示也无法消除**（观测里没有的信息，任何以观测
为条件的模型都拿不到）；q(ε|s) 定向抽签与 Top-N 线就此关闭。
（边界：配对仅取自决策 0；中途分岔可预测性需仿真中途存档分支能力才能测。）

## 5. 统一结论与三重证据

**单抽离线数据 → 状态级知识（强）；动作级知识 → 三种独立方法均不可得**：

1. RL 价值梯度（∇ₐQ 同状态方向）→ 幻觉方向，环境验证有害（§2b）
2. 事后择优（同状态 8 选 1）→ 随机水平（§3）
3. 对比排序（给了正确教材直接学）→ 随机水平（§4）

依然成立的两项能力：**状态级风险预测**（0.76–0.99，干净验证）；
**噪声彩票**（42–45%，仅可经观测失败后重试收割，事前不可择签）。

## 7. 开放路径（未做，按可行性排序）

1. **在线 RL 循环**（唯一还开着的增益路径）：仿真替真机、本地采集↔服务器训练的
   跨机流水线（各环节均已单独跑通，缺 LoRA 热替换与循环调度，估 1–2 天搭建 +
   45–60 分钟/轮）。它针对的病根（critic 缺新鲜在策略数据）与本档案各负结论不冲突；
   风险在稀疏奖励下的样本效率（论文真机结果有 19.2% 人在环纠正加成，我们没有）。
2. **"值得重试"预测器**（实用化残余价值）：状态级预测 × 失败后重试，为场景决定型
   失败省去无谓重试。工程小，收益实在。
3. **中途分岔可预测性**：需给仿真加"中途存档分支"能力后才能测——决定成败的
   信息是否在某个中间时刻进入可观测量。

## 7.5 勘误（2026-08-10，用户质疑推动的两项修正）

**勘误一：「噪声彩票」应为「重跑彩票」。**分账实验（rep0b 同噪声重跑臂 vs
rep1–8 换噪声臂，以 rep0 为基准）：同噪声纯重跑救回 6/30=20%、换噪声救回
36/202=18%——**换噪声没有可检测的额外效应**（上界约几个百分点，同噪声臂样本薄）。
"42–45% 失败可被换签救回"字面为真，但因果归因错误：救它们的是"再买一张彩票"，
彩票的熵主要来自计算不可复现性（bf16 归约顺序×接触混沌放大），不是 ε 的取值。
推论：①同状态内结局对 ε 近乎无依赖 → §4 排序器 48–54% 是**理论天花板**而非学习失败；
②重试收割机制简化——失败后重跑即可，噪声都不用换；③状态级预测（0.76–0.99）的
真实含义 = 预测场景的**边缘性**（对扰动的鲁棒程度）。后续优化目标应从"选好签"
改写为**扩大动作裕量**（让边缘场景变鲁棒），杠杆在在线 RL / 传感增强 / 数值工程。

**勘误二：措辞修正。**"完全相同输入逐比特复制仍翻转"应为"**输入**逐比特相同、
**计算过程**不保证比特级重放"（跨会话的算法重选/内存布局/调度顺序改变浮点归约
次序）；同进程内连续重放实测恒等（漂移 0.0000）。

## 8. 方法学教训（以本项目实例背书）

1. **每条结论标注证据等级**（实测/代码确认/推测），阴性结果只证伪单次实验。
2. **归因必须配外部验证臂**：A/B 对照 + 底噪零假设；绝对成功率无意义（bf16 12–20%）。
3. **归因条件化评估**：预注册标签，收益必须集中在被归因机制处才算数。
4. **训练/评测场景卫生**：裁判"背题"使评测虚高（本项目实际发生，用户抓出）。
5. **语义上界是免费的失稳报警器**（Q>1 即榨取实锤）。
6. 小数据下 **MC 分类比 TD 自举稳健**（alarm：0.62 vs 0.50）。
7. 评测脚本的静默跳场景路径 → 配对分析必须取交集。
8. 工程陷阱三连：服务端 fork 子进程僵尸（按端口模式杀全组）、pkill 自匹配
   （用 PID 列表）、"就绪标志"竞态（等目标标志本身而非前置标志）。
9. **"验证有效的机制"≠"能利用它的方法"**：换签救 42–45% 是真的，但利用它需要
   事前预测能力，而那是另一个（被证伪的）命题。
10. 诊断输出本身要验证（介入是否真的生效：饱和检验、恒等性检验、探针重放）。
