# 在线 RL 数据补充：设计文档

目标：**扩大动作裕量**——用仿真交互数据把成败信号注入权重，使边缘场景
（任何扰动都会翻转结局的 12–20%）变成鲁棒成功。不追求"选好噪声"
（已证不可行，见 RESEARCH_REPORT §7.5 勘误）。

## 算法：优势加权自我模仿（scene-baselined self-imitation）

设计完全由三条已确诊事实约束（证据见 RESEARCH_REPORT §2b/§4/§7.5）：
不用 critic 动作梯度；不做逐签归功；只用整集成败 + 场景级成功率基线。

```
迭代 k:
  采集   基座+LoRA_k 在训练池每场景 K 次自由噪声 rollout（存图像+特征）
  加权   p̂_scene = 成功数/K；成功集权重 w = (1 − p̂) + 0.1
  微调   加权流匹配损失（与预训练同构）：
         t ~ Beta(1.5,1)，ε ~ N(0,I)，x_t = t·ε + (1−t)·a_logged
         L = w · ‖v_θ(x_t, t | obs) − (ε − a_logged)‖₁，LoRA-only
  部署   新 LoRA 热载 → 下一轮
```

理论定位：REINFORCE with baseline 的拒绝采样近似（RWR/RFT 家族）；
流匹配损失充当对数似然的代理。成功 rollout 在边缘场景上就是"开对的彩票"，
克隆它们 = 把概率质量偏向好盆而不焊死。

## 场景与评测卫生

- 训练池：seed 21（2200000 段），50 场景/任务，与所有评测段零重叠
- 裁决：800 段带归因标签场景（75+25）配对 A/B，两臂均欧拉采样；
  机制指纹 = 提升集中于边缘类（原 noise_resc 标签），鲁棒失败类不动
- 快探针：每轮训练池自身成功率（应升）+ 20 场景留出小探针
- 止损：留出提升 ≤ 底噪且趋势平（约 5 轮）即停；训练升/留出降 = 场景过拟合即停

## 迭代节奏（单卡本地采集 + 服务器训练）

每轮 ≈ 采集 40 分钟/任务（50×3×~16s）→ 传输(后台) → 服务器微调 ~40 分钟
→ LoRA 回传。流水线化后 ≈ 1.5 小时/轮/任务。第 0 轮免采集：现有 corpus
112 集带图像成功 rollout 直接首轮微调。

## 备选梯队

1. ReinFlow 式策略梯度（开源参考支持 Pi0 同源）——若自我模仿停滞
2. 在线 VINE 价值梯度——诊断风险最高，最后考虑
